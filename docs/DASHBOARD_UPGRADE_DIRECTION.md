# EquiProfile Dashboard Upgrade Direction

## Product goal

The dashboard should answer three questions immediately:

1. What needs attention today?
2. Which horse should I open next?
3. What is the fastest safe action I can take?

## Recommended structure

### Top area

- Personal greeting and stable context
- Global horse/stable switcher
- Search and quick add
- Notification and account security status
- Clear subscription/role badge without persistent clutter

### Today command centre

- Overdue health actions
- Vaccinations, deworming, dental and farrier items due soon
- Appointments and training sessions today
- Tasks assigned to the user
- Weather/riding safety summary

### Horse status rail

Each horse card should show:

- Current photo and identity
- Health risk or all-clear state
- Last training session
- Next care due date
- Recent weight/fitness trend when available
- One primary action rather than many equal buttons

### Stable operations

For stable plans:

- Staff coverage and outstanding assignments
- Client/owner requests
- Unread messages
- Horses with incomplete records
- Feed and treatment cost alerts

### Insights

Use evidence-based insights derived from recorded data. Clearly label AI suggestions, missing-data warnings and non-veterinary guidance. Do not present AI output as diagnosis.

## Visual direction

- Replace the large catalogue of equal-weight module tiles with a priority-led dashboard.
- Keep a compact module launcher for secondary tools.
- Use EquiProfile's deep green, warm cream and restrained gold rather than many unrelated category gradients.
- Increase whitespace and reduce border density.
- Use one icon language and consistent card radii.
- Improve responsive hierarchy for one-handed mobile use.
- Add complete loading, empty, error, offline and permission-denied states.
- Preserve accessibility: keyboard navigation, visible focus, reduced motion, semantic headings and sufficient contrast.

## Account experience

- Security centre with password change, MFA, active sessions and sign-out-all-devices
- Email verification and secure email-change flow
- Subscription and invoice history
- Stable memberships, roles and invitations
- Data export and account deletion with re-authentication
- Consent, communication preferences and privacy controls
- Audit timeline for sensitive changes
