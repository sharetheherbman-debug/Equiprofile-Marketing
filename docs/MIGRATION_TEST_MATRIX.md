## Non-negotiable safety conditions

- Historical migrations `0014`–`0024` were **not** executed automatically.
- Historical migrations `0014`–`0024` were **not** retroactively marked as applied.
- No automatic baseline adoption exists.
- The inspector issues read-only `information_schema` queries only.
- The replay fixture is generated under ignored `.tmp/` and is never used by `scripts/migrate.sh` or application configuration.
- Partial, unknown and ambiguous states fail closed.

## Required next implementation increment

The replay diagnostic is complete, but it does not authorise a permanent strategy. The next migration increment must first obtain owner approval for a permanent fresh-install approach that preserves immutable historical files. Only then may it define one new, non-conflicting canonical forward reconciliation migration and a named supported Management baseline. That approved approach must be verified against fresh and tracked disposable database fixtures before this matrix can be marked complete.
